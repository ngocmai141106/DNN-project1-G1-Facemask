## Project Description
**Overview:** Build a DNN-based model to detect whether a person in an image is wearing face mask or not.    
**Input:** RGB images of human faces with mask on or not.    
**Output:** Binary classification result: "No_mask" or "With_mask".    
**Main steps:**    
1. Collect and preprocess the already splitted image dataset.
2. Resize and normalize the images to improve efficiency if needed.
3. Build a CNN model and train it.
4. Evaluate the model's performance with metrics such as Accuracy, Precision, Recall, F1-score, Confusion matrix, etc.
5. Optional: Test the model with new images to see how it works in pratical situations.
